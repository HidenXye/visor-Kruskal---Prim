# Visualización Kruskal y Prim — Árboles de Dependencia (MST)

Visualizador paso a paso de los algoritmos de **Kruskal** y **Prim** aplicados a datos del dataset `d9_strong.csv` particionado por `x7`. Permite explorar cómo se construye el árbol de expansión mínima (MST) arista por arista.

## Tecnologías

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/)
- [vis-network](https://visjs.github.io/vis-network/docs/network/)

## Instalación y ejecución

```bash
npm install
npm run dev
```

Abre `http://localhost:5173` en el navegador.

## Controles

| Tecla / Botón | Acción |
|---------------|--------|
| `→` | Siguiente paso |
| `←` | Paso anterior |
| `Home` | Ir al inicio |
| `End` | Ir al final |
| Auto | Reproducción automática paso a paso |
